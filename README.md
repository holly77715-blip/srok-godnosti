# Сроки годности

Офлайн-страница для подсчёта сроков годности: быстрый расчёт, записи с примечаниями (с необязательным количеством в штуках) и экспорт отчёта в txt, Excel (CSV) и PDF.
В отчёте сроки 60 дней и менее выделяются красным.
Работает как сайт на GitHub Pages и после первого открытия — без интернета.
